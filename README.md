# Pomodoro Timer

A minimalist Pomodoro technique timer built with plain HTML, CSS, and vanilla JavaScript. Designed to help manage focus sessions and break times effectively directly in the browser.

## Features

- **25-Minute Work Session**: Pre-configured default Pomodoro time block (1500 seconds).
- **Controls**: Start, Stop, and Reset/Restart functionality.
- **Audio Notification**: Custom sound effect (`fahhhhhhhhhhhhhh.mp3`) that triggers on loop once the session reaches zero.
- **Responsive & Clean UI**: Simple layout built with Flexbox.

## Tech Stack

- **HTML5**: Semantic layout and audio element handling.
- **CSS3**: Modern Flexbox layout and hover animations.
- **JavaScript (ES6+)**: `setInterval` countdown logic, DOM updates, and audio controls.
